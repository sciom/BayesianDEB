# BayesianDEB — JSS Manuscript

Manuscript for submission to the **Journal of Statistical Software**.

## Files

### Manuscript
- `bayesiandeb.tex` — Main manuscript (JSS `article` class)
- `bayesiandeb.bib` — BibTeX references (25 entries)
- `jss.cls`, `jss.bst`, `jsslogo.jpg` — JSS LaTeX class files

### Replication
- `code.R` — **Main replication script** (reproduces all tables and figures, ~3 hours)
- `sbc_validation.R` — SBC for individual model (500 reps, ~90 min)
- `sbc_hierarchical.R` — SBC for hierarchical model (50 reps, ~5 hours)
- `sbc_growth_repro.R` — SBC for growth+reproduction model (200 reps, ~3–5 hours)
- `identifiability_analysis.R` — Prior-to-posterior contraction study (~2 min, sourced by `code.R`)
- `eisenia_real_data.R` — Neuhauser (1980) case study (standalone, ~10 min)
- `debtox_vangestel.R` — Van Gestel (1991) DEBtox case study (standalone, ~2 hours)
- `sbc_results.rds` — Archived SBC results (individual, 397 valid)
- `sbc_hierarchical_results.rds` — Archived SBC results (hierarchical)

### Figures (generated by scripts)
- `fig_rawdata.pdf` — Neuhauser 1980 growth data
- `fig_trace.pdf` — MCMC trace plots
- `fig_posterior.pdf` — Marginal posterior densities
- `fig_pairs.pdf` — Bivariate posterior scatter
- `fig_trajectory.pdf` — Posterior trajectories + data
- `fig_ppc.pdf` — Posterior predictive check
- `fig_prior_predictive.pdf` — Prior predictive check
- `fig_prior_posterior.pdf` — Prior vs. posterior comparison
- `fig_sbc_ranks.pdf` — SBC rank histograms (individual)
- `fig_sbc_hierarchical.pdf` — SBC rank histograms (hierarchical)
- `fig_contraction.pdf` — Prior-to-posterior contraction
- `fig_debtox_rawdata.pdf` — Van Gestel Cd data
- `fig_debtox_doseresponse.pdf` — DEBtox dose-response

## Replication

To reproduce all results (follows paper section order):

```r
setwd("MANUSCRIPT_JSS")
source("code.R")  # ~3 hours, requires CmdStan
```

`code.R` covers:
- Section 5.1: Individual growth (simulated E. fetida)
- Section 5.2: Growth with reproduction (simulated F. candida)
- Section 5.3: Hierarchical model (simulated E. fetida, 21 individuals)
- Section 5.4: DEBtox (Van Gestel 1991 Cd data)
- Section 6.1: SBC references (loads pre-computed `.rds` files)
- Section 6.2: Identifiability analysis (sources `identifiability_analysis.R`)
- Section 7.1: Real data case study (Neuhauser 1980) + all diagnostic figures
- Section 7.2: Prior sensitivity analysis
- Section 8: Diagnostic visualisations + computational performance

For SBC validation (long-running, run separately):

```r
source("sbc_validation.R")       # ~90 min, 500 reps (individual)
source("sbc_hierarchical.R")     # ~5 hours, 50 reps (hierarchical)
source("sbc_growth_repro.R")     # ~3–5 hours, 200 reps (growth+repro)
```

## Requirements

- R >= 4.1.0
- BayesianDEB >= 0.1.2
- cmdstanr >= 0.8.0
- CmdStan >= 2.36.0
- posterior, ggplot2, GGally, deSolve, tidyr
